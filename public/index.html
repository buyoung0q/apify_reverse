실행 상세

작은 수집을 시작하는 방법

01. 수집기를 선택하세요

본문은 기사·문서 정리에, 링크는 URL 목록 만들기에, 맞춤 데이터는 상품·반복 목록 추출에 적합해요.

02. URL을 넣고 실행하세요

처음에는 최대 1~5페이지로 시작하세요. JavaScript로 표시되는 페이지는 브라우저 수집을 선택하세요. 로그인이나 CAPTCHA가 필요한 페이지는 지원하지 않아요.

03. 결과를 확인하고 내려받으세요

실행 기록을 열면 결과와 로그를 확인할 수 있어요. CSV는 엑셀에서, JSON은 다른 도구에서 활용하세요. 수집 중에도 지금까지의 결과를 받을 수 있어요.

맞춤 데이터 예시

반복 항목 .product / 필드명 name / 선택자 h2로 상품명을 추출해요. 링크가 필요하면 속성에 href를 입력하세요.

내 컴퓨터에서 실행됩니다

결과는 프로젝트의 data 폴더에 저장돼요. 예약 실행에는 앱이 켜져 있어야 해요. 실행당 최대 100페이지·5,000개 결과, 기록은 최대 200개까지 보관하며 직접 삭제할 수 있어요.

웹페이지 본문 추출의 범위

HTML 또는 브라우저에 렌더링된 텍스트를 가져와요. PDF·이미지 인식, 자동 로그인, 사이트별 맞춤 수집기는 포함되어 있지 않아요.
